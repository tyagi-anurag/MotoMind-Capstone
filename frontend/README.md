# 🏍️ MotoMind - Frontend UI

The client-side interface for **MotoMind**, built to provide a seamless, app-like experience for motorcycle diagnostics and trip planning.

## ⚡ Tech Stack
* **Framework:** [Next.js 14](https://nextjs.org/) (App Router)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/) + [Glassmorphism](https://ui.glass/)
* **Animations:** [Framer Motion](https://www.framer.com/motion/)
* **Icons:** [Lucide React](https://lucide.dev/)
* **API Client:** Axios

## 🛠️ Setup & Run

1.  **Install Dependencies:**
    ```bash
    npm install
    ```

2.  **Run Development Server:**
    ```bash
    npm run dev
    ```

3.  **Open App:**
    Navigate to [http://localhost:3000](http://localhost:3000).

## 📱 Key Features
* **Smart Onboarding:** Auto-detects user location via GPS API.
* **Trip Planner:** Responsive form layouts that adapt from mobile (stacked) to desktop (grid).
* **Rescue Map:** Integration with Google Maps API results.
* **Media Handling:** Native audio/image preview and upload handling.
